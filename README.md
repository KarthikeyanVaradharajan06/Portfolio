# Karthikeyan V — Portfolio

A clean, editorial-style personal portfolio inspired by modern minimal design.

## Structure
```
karthikeyan-portfolio/
├── index.html       # All content & sections
├── css/style.css    # Design system & responsive styles
├── js/main.js       # Nav, reveal animations, contact form
└── assets/          # (drop a profile photo here if you want)
```

## Run it
Just open `index.html` in any browser. No build step required.

For local dev with live reload:
```
npx serve .
```

## Customize
- **Colors / fonts**: edit CSS variables at the top of `css/style.css` (`--accent`, `--bg`, `--serif`).
- **Content**: edit text directly inside `index.html` sections (Hero, About, Skills, Projects, Experience, Contact).
- **Contact email**: update the `mailto:` link in `index.html` and in `js/main.js`.
